# The foundation: Core, Kernel, Contracts

**Belongs:** `Core/` holds engine-free building blocks: JSON, the record reader (`UnitytkRecords`), the run contract's generated types, `RunRules`, `ImportOrder`, `PersistedStrings`, `ProviderRule`, the one rule a record's names find their nodes by (`RecordNames`, held to pythontk's reference by its golden cases) and glTF's frame as Unity's import lands a delivery (`GltfFrame`: the X mirror, the UV origin, a record's lengths at the import's scale). It is tested by `dotnet test` in `test/core_dotnet`. `Kernel/Editor/` holds `OpContext` (its edits: `OpContextEdits`), the three operations and their servers, the provider registry, the import gate (`Imports`, and `Imports.Frame`: an importer's scale as a `GltfFrame`), `ImportLog`, a record's file found in a model's media (`MediaFiles`) and the folders an action writes into (`AssetFolders`). `Kernel/Runtime/` holds the render-pipeline host (`IRenderPipelineHost`, the registry its doors fill) and the one material writer grown from it (`MaterialWriter`: a glTF material, `LitSurface`, onto the pipeline's own Lit through the declared table `LitTable`, one row per pipeline; the mask repack, `MaskMap`). `Contracts/` holds the interfaces features meet through ([contract](contract.md)). **Does not:** name a feature, a client or a project.

**Changing it:** stop and ask: the maintainer approves every foundation change. A helper earns a place here on its second use by two parts. A new public name is published (`check_api_surface.py` reports it); a persisted string goes in `PersistedStrings`.

**Checked by:** `dotnet test`; the kernel's Edit Mode tests (`Kernel/Tests`); the live kernel tests (`test_unity_kernel_live`); `check_layers.py` (Core references nothing, the kernel only Core).
