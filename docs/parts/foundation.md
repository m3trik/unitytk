# The foundation: Core, Kernel, Contracts

**Belongs:** `Core/` holds engine-free building blocks: JSON, the record reader (`UnitytkRecords`), the run contract's generated types, `RunRules`, `ImportOrder`, `PersistedStrings`, `ProviderRule`, the one rule a record's names find their nodes by (`RecordNames`, held to pythontk's reference by its golden cases) and glTF's frame as Unity's import lands a delivery (`GltfFrame`: the X mirror, the UV origin, a record's lengths at the import's scale). It is tested by `dotnet test` in `tests/core_dotnet`. `Kernel/Editor/` holds `OpContext` (its edits: `OpContextEdits`, with the one plan key a part's action asks by, `OpContextEdits.Key`, and `PlannedObject`, what an action is handed for an object a dry run only planned), a scene's top-level objects by name (`SceneRoots`), the three operations and their servers, the provider registry, the import gate (`Imports`, and `Imports.Frame`: an importer's scale as a `GltfFrame`), `ImportLog`, a record's file found in a model's media (`MediaFiles`), the one reader of an event's saved calls (`PersistentCalls`: what each calls and passes, and whether a call is wired already), the folders an action writes into (`AssetFolders`), the one hook around a write of a scene or a prefab (`SaveSuspension`: each `ISaveSuspended` in the open scenes, and each editor keeper added, gives back what the file would save of it before the write, and each one asked takes it again after, the last first; one that throws is said and the rest still asked) and the editor's icon set (`VectorIcons`, `VectorIcon`: the ecosystem's shared SVGs, copied into `Kernel/Editor/Icons/` by `sync_unity_icons.py`, never edited by hand). `Kernel/Runtime/` holds the render-pipeline host (`IRenderPipelineHost`, the registry its doors fill, a display transform's `DisplayOptions`), the one subscriber to Unity's per-camera render callbacks (`CameraDrawing`: each camera starting and ending its drawing, whichever pipeline raises which) and the one material writer grown from it (`MaterialWriter`: a glTF material, `LitSurface`, onto the pipeline's own Lit through the declared table `LitTable`, one row per pipeline; the mask repack, `MaskMap`), and the scene helpers several parts ask: what is seen of a part (`SceneBounds`, and its renderers for a component that asks every frame), the viewer's eyes (`Viewer`), what a panel before them hides (`PanelCover`), the scene's switched-on component of a kind (`SceneObjects`) and what a component that edits a scene it must not save implements (`ISaveSuspended`). `Contracts/` holds the interfaces features meet through ([contract](contract.md)) and the readers of the records two features read (`MaterialRecord`; `HandoffBlock`, in the namespace `M3trik.Unitytk.Contracts`, as every new type there). `Kernel/URP/` is the foundation's one door: URP's host (`UniversalRenderPipelineHost`), registered as it loads where URP is installed. **Does not:** name a feature, a client or a project.

**Changing it:** stop and ask: the maintainer approves every foundation change. A helper earns a place here on its second use by two parts. A new public name is published (`check_api_surface.py` reports it); a persisted string goes in `PersistedStrings`.

**Checked by:** `dotnet test`; the kernel's Edit Mode tests (`Kernel/Tests`); the live kernel tests (`test_unity_kernel_live`); `check_layers.py` (Core references nothing, the kernel only Core).
