# unitytk

The automation beside the unitytk Unity package ([`com.m3trik.unitytk/`](../com.m3trik.unitytk/README.md), installed into a project by Unity's Package Manager, never by pip).

The Python side drives Unity from outside, with Unity's own tools: `UnityHost` (the `unity` operation host: calls in an editor this tooling starts and owns, never one a person opened; `install` writes the one manifest line that installs the package), `ProjectBuilder` (the test and demo project, made on demand by Unity's CLI and linked to this checkout) and `UnityCompile` (the package's C# compiled in seconds, no editor running).
